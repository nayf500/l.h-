# Saudi Plate Editable Code V2

التعديل الجديد:
عند تغيير الحروف العربية، يتم تحويلها تلقائياً إلى الحروف الإنجليزية المقابلة.

مثال:
ع ع ب -> E E B
ا ب ح -> A B J
د ر س -> D R S

الحروف الإنجليزية أصبحت للعرض فقط ولا يمكن تعديلها يدوياً حتى تبقى مرتبطة بالحروف العربية.

الملفات:
- index.html
- style.css
- script.js
- README.txt

ارفع الملفات إلى مشروع الموقع، أو استبدل الملفات الموجودة في النسخة السابقة بهذه النسخة.
