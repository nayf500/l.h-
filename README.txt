# Saudi Plate Editable Code

هذا المشروع يحتوي على لوحة سعودية بأسلوب واقعي للمحاكاة داخل موقع المزاد.

الملفات:
- index.html
- style.css
- script.js

طريقة الاستخدام:
1. ارفع الملفات الثلاثة إلى مشروعك.
2. افتح index.html.
3. عدّل الحروف والأرقام من الحقول.
4. اللوحة تتغير مباشرة.
5. زر "حفظ اللوحة كـ SVG" يصدر نسخة SVG.

ملاحظة:
القالب مخصص لواجهة موقع المزاد والمحاكاة الرقمية فقط، وليس لإنتاج لوحة رسمية أو استخدامها على مركبة.
