# مزاد مسارك - V2
هذه النسخة أعيد بناؤها من الصفر مع التركيز على مطابقة لقطة الشاشة نفسها، خصوصاً:
- تخطيط الهاتف الضيق.
- ترتيب رأس الموقع.
- بطاقة العد التنازلي الخضراء.
- بطاقة اللوحة الحالية.
- شكل بطاقة السعر.
- إعادة رسم لوحة السعودية بنفس تقسيم الصورة: الأرقام | الشعار/السعودية | الحروف.
- ألوان وهوامش وحجوم أقرب للصورة.

هذه ما زالت نسخة واجهة Front-End. المرحلة التالية هي ربط نفس الواجهة بقاعدة البيانات والمزايدة الحقيقية دون تغيير التصميم.
